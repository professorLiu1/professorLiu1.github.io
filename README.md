# 试用期工作痕迹记录（工艺工程师）

## 目的

做好工作过程留痕，完整记录工作开展过程、异常分析过程、专业知识学习，不仅记录最终结果。将口头经验转化为书面资料，便于周报汇报、工作复盘以及转正总结。

共建立三本台账，内容可直接复制到 Word；表格可直接复制到 Excel。

---

## 台账一：每日工作台账

**用途**：日常工作逐项登记，完整留存工作过程与工作产出。

| 日期 | 工作内容 | 执行过程 | 输出物/文档编号 | 遇到的问题 | 处理措施 | 结果与进展 | 个人收获 |
| --- | --- | --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  |  |  |
|  |  |  |  |  |  |  |  |
|  |  |  |  |  |  |  |  |

### 填写说明

1. **工作内容**：简明填写任务名称；
2. **执行过程**：简述自己开展工作的方式；
3. **输出物**：报告、统计表、试验方案、会议纪要、联络单，填写文档名称；
4. **遇到的问题**：技术异常、资料缺失、跨部门沟通卡点；
5. **处理措施**：本人采取的行动，咨询同事、领导情况；
6. **结果进展**：已完成 / 进行中-阶段 / 待跟进；
7. **个人收获**：工艺知识、分析方法、沟通经验。

### 示例

2026-09-09，拼板分层不良分析，收集不良条码编码，拆分单元位置、工单信息；输出《分层不良统计表》；不良集中于 06、08 单元位置，根因暂不明确；调取 MI 核对基材型号，计划核查洗刀程序；数据分析完成，待工艺确认根本原因；个人收获：掌握编码拆解，学会工单-位置交叉数据分析思路。

## 台账二：问题跟踪闭环台账（转正核心亮点）

**用途**：所有品质异常、技术问题、待协调事项登记，做到事事可追溯、事事有闭环。

| 序号 | 事项描述 | 发现时间 | 现状情况 | 分析过程 | 采取行动 | 责任人 | 当前状态 | 结论/改善结果 | 经验总结 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  |  |  |  |  |
|  |  |  |  |  |  |  |  |  |  |
|  |  |  |  |  |  |  |  |  |  |

### 填写说明

1. 无论本人主导或参会参与的质量异常，均进行登记；
2. 分析过程重点记录自己的思考过程；
3. 经验总结明确本次问题获得的经验，以及后续规避同类问题的方法。
